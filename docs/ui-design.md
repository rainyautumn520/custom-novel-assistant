## 1. 设计定位

UI 风格 = **Obsidian 的知识密度 × Notion 的清晰排版 × Codex 的工程质感**：

| 来源 | 取什么 | 不取什么 |
|---|---|---|
| Obsidian | 暗色知识工作氛围、双栏面板、实体关联感 | 过度花哨的图谱动效 |
| Notion | 克制的卡片、清晰层级、大量留白、数据库式列表 | 办公套件感 |
| Codex | 等宽字体点缀、状态可见、快捷键文化、精确的反馈 | 终端风格堆砌 |

默认**暗色主题**，亮色主题作为可选项（令牌化实现，不单独设计）。

## 2. 视觉令牌（Design Tokens）

### 2.1 色彩（暗色主题）

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#1b1b20` | 应用背景 |
| `panel` | `#232329` | 面板/侧栏 |
| `panel-2` | `#2b2b33` | 卡片/输入区 |
| `border` | `#34343d` | 边框、分隔线 |
| `hover` | `#2f2f38` | 悬停底色 |
| `active` | `#3a3a45` | 选中底色 |
| `text-primary` | `#e8e8ec` | 主文字 |
| `text-secondary` | `#a0a0ac` | 次要文字 |
| `text-muted` | `#6f6f7a` | 弱化/占位 |
| `accent` | `#7c6ff0` | 主强调（紫） |
| `accent-hover` | `#8f84f5` | 强调悬停 |
| `success` | `#4caf7d` | 已保存/成功 |
| `warning` | `#d9a13b` | 保存中/警告 |
| `danger` | `#e05d5d` | 错误/删除 |
| `info` | `#5b9bd5` | 信息/链接 |

强调色只用于：主按钮、当前导航、选中态、焦点环。不用于大面积背景。

### 2.2 字体与字号

| 用途 | 字体栈 |
|---|---|
| UI / 正文 | `system-ui, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 数字 / 代码 / 字数 | `ui-monospace, "JetBrains Mono", Consolas, monospace` |

| 令牌 | 值 | 用途 |
|---|---|---|
| `text-xs` | 12px | 辅助信息、快捷键 |
| `text-sm` | 13px | 次要内容、标签 |
| `text-base` | 14px | 默认 UI |
| `text-lg` | 16px | **正文编辑最小字号（PRD 要求）** |
| `text-xl` | 20px | 页标题 |
| `text-2xl` | 24px | 模块标题 |

正文行高 `1.8`，UI 行高 `1.5`。

### 2.3 间距 / 圆角 / 阴影 / 动效

- 间距：4 / 8 / 12 / 16 / 24 / 32。
- 圆角：组件 4px，卡片 8px，弹窗 12px。
- 阴影：暗色下用 `0 1px 2px rgba(0,0,0,.3)`，弹窗 `0 8px 24px rgba(0,0,0,.45)`。
- 动效：120–160ms 缓动；只用于状态变化，不做持续动画。

## 3. 应用骨架（五区布局）

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 48px：作品切换 · 全局搜索 · 保存状态 · 设置              │
├──────────┬───────────────────────────────────┬───────────────┤
│          │                                   │               │
│ 左导航   │       中央工作区（弹性）           │ 右上下文栏    │
│ 220px    │                                   │ 300px         │
│ (可收起  │   列表/树 + 内容编辑 主区域         │ (可收起)      │
│  64px)   │                                   │ 属性/引用/    │
│          │                                   │ 章纲合同/AI   │
│          │                                   │               │
├──────────┴───────────────────────────────────┴───────────────┤
│ 底栏 28px：字数 · 保存状态 · 快捷键提示                      │
└──────────────────────────────────────────────────────────────┘
```

布局规则：

- 左导航：模块入口 + 当前模块高亮；宽 220px，可收起为图标栏。
- 右上下文栏：默认展开（编辑器内可收起，为写作留出空间）。
- 切换模块时保持：当前作品、当前选中对象、保存状态。
- 任何详情对象都有稳定深链接（如 `#/workspace/:id/outline/node/:nid`）。
- 窗口缩放最小 1100×700，低于时优先收起侧栏。

## 4. 组件规范

### 4.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| primary | accent 底、白字 | 主操作：新建、保存、确认 |
| secondary | panel-2 底、border | 次要操作 |
| ghost | 透明、hover 底 | 行内操作、工具栏 |
| danger | danger 底 | 删除等高风险（需配确认） |

尺寸：默认 h32px、padding 12px；小 h24px（树内/表格内）；带图标时文字左侧。

### 4.2 保存状态（三态，PRD 强制）

文字 + 圆点，**禁止只用图标**：

```text
● 保存中…   （warning，转圈）
● 已保存    （success，勾）
● 保存失败  （danger，点击重试）
```

失败时保留页面内提示（不依赖 Toast），并提供"复制全文"兜底。

### 4.3 树组件（大纲 / 分类）

- 每行：拖拽手柄、层级缩进、类型图标（卷/章/细纲）、标题、状态徽标。
- 拖拽时显示合法放置线；非法父级置灰并拒绝。
- 键盘：↑↓ 移动、←→ 折叠/展开、Space 选中、F2 重命名、Del 删除（带确认）。
- 章纲行附带目标字数与完成状态。

### 4.4 列表与卡片

- 列表：紧凑表格风（标题、更新时间、字数、状态、操作），适合设定/素材/章节。
- 卡片：网格风（封面、标题、摘要），适合作品首页、人物。
- 搜索框统一在模块右上：输入即过滤，显示"类型 + 标题 + 命中摘要 + 所在作品"。

### 4.5 空状态

```text
  [图标]
  当前还没有「设定条目」
  从第一条世界观规则开始，或导入已有笔记。
  [创建第一条设定]  [导入 Markdown]
```

规则：说明用途 + 唯一主操作；不得以空白页代表异常。

### 4.6 对话框

- 危险操作（删除/覆盖）：标题 + 影响范围说明 + 取消/确认（确认默认 danger）。
- 确认按钮始终在右侧；关闭按钮可 Esc。
- 删除前显示引用影响（如"被 2 个人物、5 个章节引用"）。

### 4.7 Toast

- 只报告短暂结果（复制成功、导出完成）。
- 需要用户处理的失败必须留在页面内，不依赖 Toast。

## 5. 页面线框

### P01 项目首页

```text
┌──────────────────────────────────────────────────┐
│ AI Novel IDE                        [设置]       │
├──────────────────────────────────────────────────┤
│  继续写作                                          │
│  ┌────────────────────────────────────────────┐  │
│  │ 《大梦山海》  第 37 章 · 2,148 字    [继续] │  │
│  └────────────────────────────────────────────┘  │
│  最近作品                                          │
│  ┌────────┐ ┌────────┐ ┌────────┐                │
│  │封面缩略│ │封面缩略│ │封面缩略│  [+ 新建作品]  │
│  │大梦山海│ │剑起沧澜│ │星海拾遗│                │
│  │2.1万字  │ │8.7万字  │ │3.4万字  │                │
│  └────────┘ └────────┘ └────────┘                │
│  已归档（1）                                       │
└──────────────────────────────────────────────────┘
```

首屏优先级：继续写作 > 最近作品 > 新建 > 归档。空状态只显示"新建作品"主操作。

### P02 新建作品

弹窗式，字段：书名*、题材、简介、预计字数、存储位置（默认数据目录）。
创建后直接进入作品概览，并展示"设定→人物→大纲→正文"引导。

### P03 作品概览

```text
┌ 顶栏：作品切换 · 搜索 · 保存状态 · 设置 ┐
├ 左导航 ├ 概览                        ├ 右栏：最近编辑 ┤
│        概览   ├ 统计卡：总字数/章节数/   │  - 第37章 2,148字
│        设定   │ 本周新增/今日新增        │  - 大纲：北境联盟
│        人物   ├ 最近章节列表（3条）      │  - 设定：灵气复苏
│        大纲   ├ 待办引导：                │
│        正文   │  □ 建立第一条设定         │
│        素材   │  □ 创建第一卷大纲         │
│        导出   │  □ 写第一章（可跳过）     │
└──────────┴──────────────────────────┴──────────────┘
```

### P04 设定库

```text
┌ 顶栏 ┐
├ 左导航 ├ 分类树(左) │ 条目列表(中) │ 编辑器(右)      ┤
│        │ 全部      │ □ 标题  标签  状态  更新 │ 标题：[___] │
│        │ ├ 规则    │  灵气复苏 [设定] [已确认] │ 分类：规则   │
│        │ ├ 地理    │  天元大陆 [地理] [草稿]  │ 标签：[+添加] │
│        │ ├ 历史    │  …                     │ 状态：已确认   │
│        │ └ 势力    │                        │ ┌Markdown 编辑┐│
│        │           │                        │ │ 正文...     ││
│        │           │                        │ └─────────────┘│
│        │           │                        │ 引用：人物(2)   │
└────────┴───────────┴────────────────────────┴───────────────┘
```

分类单选用于归档，标签多选用于横向检索。`confirmed` 状态以徽标突出（AI 硬约束）。

### P05 人物库

左：人物列表（筛选/搜索）；右：角色卡编辑（姓名、别名、身份、性格、外貌、背景、目标、标签、备注）。
卡片视图与列表视图可切换；关联设定通过右栏"关联"展示。

### P06 大纲编排

```text
┌ 顶栏 ┐
├ 左导航 ├ 大纲树(左 40%) │ 节点编辑(中) │ 引用(右)   ┤
│        │ ▸ 第一卷 灵起    │ 标题：第3章 初入天元  │ 引用设定  │
│        │   ▸ 第1章 …      │ 目标：…              │  灵气复苏 │
│        │   ▸ 第2章 …      │ 必须覆盖：…          │ 出场人物  │
│        │   ▸ 第3章 初入…  │ 禁区：…              │  林晚(2)  │
│        │     · 细纲1      │ 状态：active 目标字数： │  - 张小凡  │
│        │     · 细纲2      │ [从章纲创建正文]        │  - 苏月   │
│        │ + 新建卷          │                        │          │
└────────┴─────────────────┴───────────────────────┴──────────┘
```

拖拽原子保存、失败回滚；非法父级拒绝；删除父节点前提示子节点数。

### P07 正文编辑器

```text
┌ 顶栏 ┐
├ 左导航 ├ 章节树(左 200px) │ 编辑区(弹性) │ 上下文栏(300px) ┤
│        │ ▸ 第一卷         │ [第3章 初入天元] │ 章纲合同        │
│        │   ▸ 第1章 ✓      │ ● 已保存 · 2,148字 │ 目标/必须覆盖/禁区 │
│        │   ▸ 第2章 ✓      │ ┌─ CodeMirror ─┐ │ 相关人物        │
│        │   ▸ 第3章 ●      │ │ 正文…        │ │ 相关设定        │
│        │ + 新建章节        │ └──────────────┘ │ AI 面板(v0.2)  │
│        │                  │ [预览] [导出] [快照]│ [讨论] [续写] │
└────────┴──────────────────┴──────────────────┴───────────────┘
```

关键规则：字号 ≥16px；自动保存 800–1500ms 防抖；保存三态常驻；预览与 AI 面板可收起。

### P08 素材库

列表/卡片切换；字段：标题、类型（文本/文件）、来源、标签、备注；搜索 + 标签过滤。

### P09 导出中心

```text
导出类型: [单章] [全书]
范围:     章节清单（预览，按大纲顺序）
选项:     □ 包含卷名  □ 包含章名  编码: UTF-8
目标:     [路径输入]  [选择…]
预计:     35 章 · 12.4 万字 · 3.2 MB
                      [取消] [开始导出]
结果:     成功 35/35 | 失败项可重试
```

覆盖同名文件必须确认；失败给出未导出项清单。

### P10 全局设置

左侧分组：外观与编辑器 / 数据与备份 / 快捷键 / AI 服务与凭证（v0.2）。
外观含主题（暗/亮）、字号、行高、编辑区宽度。

### P11–P13（v0.2，线框从简）

- **P11 AI 设置**：提供商、模型、连通测试、凭证状态（只显示"已配置/未配置"）、安全说明。
- **P12 设定讨论**：会话列表（左）/ 对话流（中）/ 当前引用上下文（右）；"纳入设定"按钮在选中结论后出现，进入预览确认。
- **P13 封面工坊**：分步向导：需求 → 优化提示词 → 候选图 → 文字排版 → 导出；任务状态可见（排队/生成中/成功/失败/取消）。

## 6. 全局交互规则

| 规则 | 说明 |
|---|---|
| 创建 | 主按钮；编辑自动保存；显式"保存"只用于高风险配置或 AI 结果纳入 |
| 删除 | 危险样式 + 二次确认；能恢复的优先归档/回收站 |
| 拖拽 | 提供键盘替代与撤销入口 |
| 搜索 | 结果统一显示类型、标题、命中摘要、所在作品 |
| 空状态 | 解释用途 + 唯一主操作 |
| 快捷键 | Ctrl/Cmd+S 保存、Ctrl/Cmd+K 命令面板、Ctrl/Cmd+F 搜索、Ctrl/Cmd+P 预览、Ctrl/Cmd+, 设置 |

## 7. 可访问性

- 焦点环使用 accent 2px；主要功能键盘可达。
- 状态不只用颜色表达（保存三态含文字、按钮含文字）。
- 对比度：正文文字与背景 ≥ 7:1，次要文字 ≥ 4.5:1。
